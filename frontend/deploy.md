# Publicar la vista online

La forma más simple y gratis es usar GitHub Pages o Vercel.

## Opción recomendada: Vercel
1. Sube la carpeta frontend a GitHub.
2. Entra a https://vercel.com.
3. Importa el repositorio.
4. Selecciona la carpeta frontend como raíz del proyecto.
5. Vercel publica la web automáticamente.

## Opción alternativa: GitHub Pages
1. Sube el contenido de frontend a un repositorio.
2. Activa GitHub Pages desde Settings > Pages.
3. Elige la rama principal y publica.
