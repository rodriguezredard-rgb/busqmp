# Peken v2.0

Proyecto para identificar oportunidades de mercado público, incluyendo licitaciones y compras ágiles, pensado para crecer en la nube.

## Arquitectura
- Backend: Python + FastAPI
- Frontend: React + Vite
- Base de datos: SQLite para desarrollo, PostgreSQL/Supabase para producción

## Estructura
- backend/: API y lógica de negocio
- frontend/: interfaz web

## Despliegue sugerido
- Frontend: Vercel
- Backend: Render o Railway
- Base de datos: Supabase o Neon
